Overlay pages

    Patterns: an overlay page that follows the page you're on

    Add a URL with placeholders, filled in from the page you're on: {path} is its path, {query} its ?query and {hash} its #hash. {-'.html'} removes .html from the end if it's there; {+'.html'} adds it if it's missing.

    On site.com/en/page.html, main--site--org.aem.page{path}{-'.html'} opens main--site--org.aem.page/en/page, and on that page, site.com{path}{+'.html'} leads back.

      Get it from GitHub (git pull or download), then reload FullyFrame in chrome://extensions.
