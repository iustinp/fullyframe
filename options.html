When set, the first click loads this page on top of the detected iframe. Further clicks (or Alt+Space / ⌥+Space on Mac) flip between the custom page and the original without reloading, so you can compare them. Press Esc to close the overlay. Leave empty to make the detected iframe fullscreen instead.

Alt+click (⌥+click on Mac) on any text in either page scrolls the same text in the other page to the same height, so the two line up when you flip.

While the overlay is active, this page's anti-framing headers (X-Frame-Options and Content-Security-Policy) are removed for that tab only, so sites that normally refuse to be embedded can load.
